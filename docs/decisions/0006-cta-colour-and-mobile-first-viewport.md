# 0006 — สีของ CTA, จอแรกบนมือถือ และ contrast ของหน้าหลัก

วันที่: 2026-09-15 · สถานะ: Implemented (ยังไม่ commit) · ต่อจาก [0005](0005-seo-performance-first-motion.md) · แทนบางส่วนของ [0003](0003-scroll-storytelling-home.md)

ที่มา: critique หน้าหลัก (`.impeccable/critique/2026-09-15T13-38-41Z__apps-web-features-home-components-home-page-tsx.md`) Developer เลือกแก้เฉพาะ P1 ทั้ง 3 ข้อ และให้ปุ่มหลักยังเป็น "ขอราคาน้ำ" · รายละเอียดงาน: [handoff](../evaluation/tasks/2026-09-15-home-critique-p1-fixes.md)

## กฎที่ใช้ต่อ

1. **สีแดง (`variant: "call"`) ใช้กับลิงก์ `tel:` เท่านั้น** ลิงก์ไป `/quote` ใช้สีเขียว (`default`) บนพื้นเขียวเข้ม (`bg-surface-dark`) ใช้ปุ่มขาว `bg-white text-surface-dark` เพราะเขียวบนเขียวเข้มแยกจากพื้นได้แค่ 1.9:1
2. **ต่ำกว่า 900px แถบ sticky ล่างจอเป็นเจ้าของปุ่มโทร/LINE/ขอราคา** header ไม่แสดงปุ่ม "ขอราคาน้ำ" และ hero ไม่แสดงปุ่มโทร (เดิมปุ่มโทรใน hero ถูกแถบบังทั้งปุ่ม) ปุ่มในแถบสูง 56px ตาม handoff
3. **เกจในบทขั้นตอนแสดงความคืบหน้าของขั้นตอน ไม่ใช่ลิตร** ป้ายคือชื่อขั้นแรกและขั้นสุดท้าย (ป้าย "ปริมาณน้ำต่อเที่ยว · 20,000 ลิตร" เดิมอ่านเหมือนยอดสั่งขั้นต่ำ) และลบ field `process.gaugeLabel` ออกจาก schema แล้ว
4. **ขั้นตอนที่ยังไม่ถึงกลางจอจางได้ถึง opacity 0.8 เท่านั้น** (เดิม 0.35 ทำให้ข้อความเหลือราว 1.8:1) วงกลมเลขขั้นตอนเป็นตัวบอกว่าอยู่ขั้นไหน
5. **แถบตัวเลขใช้ `bg-surface-dark`** ตาม handoff (label บน `bg-primary` ได้แค่ 3.9:1) · token `--star` ธีมสว่างเป็น `#b7790f` (3.65:1 บนขาว)
