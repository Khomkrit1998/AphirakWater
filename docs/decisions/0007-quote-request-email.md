# 0007 — ส่งคำขอใบเสนอราคาทางอีเมล (Resend)

วันที่: 2026-09-15 · สถานะ: Implemented · ต่อจาก [0001](0001-website-phase-1.md) ข้อ 6 และ [0002](0002-admin-preview-and-home-composition.md) ข้อ 3

## Decision

Developer เลือกให้ `POST /api/quote` ส่งคำขอเป็นอีเมลก่อน ส่วนการบันทึกลง database และ CMS ตัดสินใจภายหลัง

| เรื่อง | ตัดสินใจ | เหตุผล |
| --- | --- | --- |
| ผู้ให้บริการ | Resend เรียกผ่าน REST API ด้วย `fetch` | ไม่ต้องเพิ่ม dependency (ไม่ใช้ SDK), ไม่ต้องมี SMTP, ใช้ได้ทั้ง Vercel และ VPS |
| รูปแบบอีเมล | ข้อความล้วน (text) | ไม่ต้อง escape HTML จากข้อมูลที่ลูกค้ากรอก, Gmail ทำเบอร์โทรเป็นลิงก์ให้เอง |
| เลขอ้างอิง | `AW-YYMMDD-XXXX` (วันที่ตามเวลาไทย + hex 4 ตัว) | ยังไม่มี database ใช้จับคู่หน้าจอลูกค้ากับหัวเรื่องอีเมลเท่านั้น |
| ยังไม่ตั้งค่า env | ตอบ 503 ให้ลูกค้าโทร (เหมือนเดิม) | เว็บ build และเปิดได้ก่อนตั้งค่าอีเมล และไม่บอกลูกค้าว่าส่งสำเร็จถ้าอีเมลไม่ได้ออกไปจริง |
| Resend ปฏิเสธหรือเกิน 10 วินาที | ตอบ 502 ให้ลูกค้าโทร และ log สาเหตุ (ไม่ log ข้อมูลลูกค้า) | |

## Environment variables (ฝั่ง server ของ `apps/web`)

| ตัวแปร | จำเป็น | ค่า |
| --- | --- | --- |
| `RESEND_API_KEY` | ✓ | API key จาก resend.com |
| `QUOTE_EMAIL_TO` | ✓ | อีเมลผู้รับ คั่นหลายอีเมลด้วย `,` |
| `QUOTE_EMAIL_FROM` | — | ค่าเริ่มต้น `Apirak Water <onboarding@resend.dev>` |

ตรวจด้วย zod ใน `apps/web/lib/env.ts` (`getQuoteEmailEnv`) ตอนมี request ไม่ใช่ตอน build และประกาศไว้ใน `globalPassThroughEnv` ของ `turbo.json` แล้ว (turbo จะไม่กรองทิ้ง และค่าไม่มีผลต่อ cache)

ตอน dev ให้ใส่ใน `apps/web/.env.local` (`.env*` อยู่ใน `.gitignore` แล้ว)

## วิธีเปิดใช้งาน

1. สมัคร resend.com **ด้วยอีเมลที่ต้องการรับคำขอ** แล้วสร้าง API key
2. ตั้ง `RESEND_API_KEY` และ `QUOTE_EMAIL_TO` (เป็นอีเมลที่ใช้สมัคร) บน server แล้ว restart
3. ส่งฟอร์มทดสอบที่ `/quote` หนึ่งครั้ง

**ข้อจำกัดของผู้ส่ง `onboarding@resend.dev`:** ส่งได้เฉพาะไปยังอีเมลที่สมัคร Resend เท่านั้น ถ้าต้องการหลายผู้รับหรือชื่อผู้ส่งเป็นโดเมนของกิจการ ต้อง verify โดเมนใน Resend (เพิ่ม DNS record) แล้วตั้ง `QUOTE_EMAIL_FROM` เช่น `อภิรักษ์บริการน้ำ <quote@โดเมนจริง>`

## ยังไม่ได้ทำ

* ~~ไม่มีการกันสแปม~~ ทำแล้วด้วย honeypot + เวลากรอก ดู [0008](0008-quote-form-spam-protection.md) (ยังไม่มี Turnstile / rate limit)
* ไม่บันทึกคำขอลง database ถ้าอีเมลส่งไม่สำเร็จ คำขอนั้นจะไม่ถูกเก็บไว้ (ลูกค้าเห็นข้อความให้โทร)
* ถ้า Resend ตอบช้าเกิน 10 วินาทีแต่ส่งสำเร็จจริง ลูกค้าจะเห็นข้อความให้โทร ขณะที่อีเมลก็ถึง (อาจได้คำขอซ้ำ)
* GA4 `generate_lead`, แจ้งเตือนทาง LINE, อีเมลยืนยันถึงลูกค้า (ฟอร์มไม่มีช่องอีเมล)
